Features

What an organization needs, and nothing more

We cut the features that do not matter so the system stays light, fast and easy for a small IT team to run.

Your data stays yours

Runs on your server or cloud account. Nothing is sent to a vendor. Meets data-residency and privacy requirements.

Light and fast

A single binary plus PostgreSQL serves a whole company on a small machine. No Kubernetes, no extra operators.

Announcement channels

HR and management reach everyone for sure, with "seen by" counts, instead of getting lost in group chatter.

Control from one place

Add, remove or suspend accounts the moment someone leaves. Restrict sign-ups to your email domain.

Auditable

Audit log for logins and admin actions. File and image sharing stored on your disk or your S3 bucket.

Bots for your systems

ERP, HR, ticketing or monitoring can post into chat with a single HTTP call.

Bot API

If you have written a Telegram bot, you already know it

Create a bot in the admin page, get a token, and send. Long-polling and webhooks are both supported.

curl -X POST https://chat.example.com/bot/<TOKEN>/sendMessage \
  -H "Content-Type: application/json" \
  -d '{"chat_id": 42, "text": "Deploy of v1.4.2 succeeded"}'
Self-host

Installed in 15 minutes, updated with one command

git clone https://github.com/b1ll1eee/messario && cd messario/deploy
cp .env.example .env   # MESSARIO_DOMAIN, POSTGRES_PASSWORD, MESSARIO_LICENSE
docker compose up -d
docker compose exec messario /app/messario init --org "Your Company" --admin admin --password '...'
