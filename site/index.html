แชทองค์กรแบบติดตั้งในบ้านตัวเอง

แชทของบริษัทคุณ บนเครื่องของบริษัทคุณ

Messario คือระบบแชทสำหรับองค์กรที่ติดตั้งบนเซิร์ฟเวอร์ของคุณเอง เบาเท่าไฟล์เดียว ต่อระบบงานได้ด้วย Bot API แบบเดียวกับ Telegram และข้อมูลไม่ออกจากบริษัท

ติดตั้งใน 15 นาที อ่านเอกสาร
รองรับ PDPACommunity edition ฟรี 10 ที่นั่งภาษาไทยเป็นภาษาหลัก
ฟีเจอร์

สิ่งที่องค์กรต้องการ ไม่มากไปกว่านั้น

ตัดฟีเจอร์ที่ไม่จำเป็นออก เพื่อให้ระบบเบา เร็ว และดูแลง่ายสำหรับทีม IT ขนาดเล็ก

ข้อมูลอยู่กับคุณ

ติดตั้งบนเซิร์ฟเวอร์หรือคลาวด์ของบริษัท ไม่มีข้อมูลวิ่งออกนอกองค์กร ตอบโจทย์ PDPA และนโยบายความปลอดภัย

เบาและเร็ว

ไฟล์เดียวกับฐานข้อมูล PostgreSQL รองรับคนทั้งบริษัทบนเครื่องเล็กๆ ไม่ต้องมี Kubernetes

ช่องประกาศทางการ

ประกาศจากฝ่ายบุคคลและผู้บริหารถึงทุกคนแน่นอน ไม่จมหายในกลุ่ม พร้อมดูได้ว่าใครเห็นแล้ว

ควบคุมได้จากที่เดียว

เพิ่ม ลบ ระงับบัญชีทันทีที่พนักงานลาออก จำกัดการเข้าใช้ด้วยโดเมนอีเมลของบริษัท

ตรวจสอบย้อนหลังได้

บันทึกการเข้าใช้และการเปลี่ยนแปลง (audit log) ส่งไฟล์และรูปได้ เก็บบนดิสก์หรือ S3 ของคุณเอง

บอทต่อระบบงาน

ERP, HR, ระบบแจ้งซ่อม หรือ monitoring ส่งแจ้งเตือนเข้าแชทได้ด้วย HTTP เพียงคำสั่งเดียว

Bot API

เคยเขียน Telegram bot ก็ใช้ได้ทันที

รูปแบบ API เดียวกับที่นักพัฒนาคุ้นเคย สร้างบอทจากหน้าผู้ดูแล รับโทเคน แล้วยิงข้อความได้เลย รองรับทั้ง long-polling และ webhook

  • ส่งข้อความและไฟล์เข้าห้องหรือช่องประกาศ
  • รับคำสั่ง /command จากผู้ใช้ผ่าน getUpdates หรือ webhook
  • จำกัดอัตราการส่งต่อบอท ป้องกันระบบล่ม
# ส่งแจ้งเตือนจากระบบงานเข้าห้องทีม
curl -X POST https://chat.yourcompany.co.th/bot/<TOKEN>/sendMessage \
  -H "Content-Type: application/json" \
  -d '{"chat_id": 42, "text": "Deploy production v1.4.2 สำเร็จ"}'

# ตอบกลับ
{"ok": true, "result": {"chat_id": 42, "seq": 1874, ...}}
ติดตั้งเอง

ติดตั้งเสร็จใน 15 นาที อัปเดตด้วยคำสั่งเดียว

01

เตรียมเครื่อง

Linux เครื่องเดียว 2 vCPU 4 GB ก็เพียงพอสำหรับพนักงานหลายร้อยคน จะเป็นเซิร์ฟเวอร์ในบริษัทหรือ VPS ก็ได้

02

รัน Docker Compose

ไฟล์เดียวรวม Messario, PostgreSQL และ Caddy ที่ออกใบรับรอง HTTPS ให้อัตโนมัติ ใส่โดเมนกับ license key แล้วรันได้ทันที

03

เชิญพนักงาน

กำหนดโดเมนอีเมลของบริษัท เพิ่มผู้ใช้จากหน้าผู้ดูแล ใช้งานได้ทั้งบนเว็บและมือถือ

git clone https://github.com/b1ll1eee/messario && cd messario/deploy
cp .env.example .env   # ตั้ง MESSARIO_DOMAIN, POSTGRES_PASSWORD, MESSARIO_LICENSE
docker compose up -d
docker compose exec messario /app/messario init --org "บริษัทของคุณ" --admin admin --password '...'

คำถามที่พบบ่อย

ต่างจาก LINE อย่างไร

LINE เป็นแอปส่วนตัวที่ข้อมูลอยู่กับ LINE และบริษัทจัดการสมาชิกไม่ได้ Messario ติดตั้งในบริษัท ผู้ดูแลเพิ่มและลบคนได้ทันที และมี audit log

ต้องมีทีม IT ขนาดไหน

คนเดียวที่เคยใช้ Docker ก็ติดตั้งได้ การอัปเดตใช้คำสั่งเดียว

มีแอปมือถือไหม

ใช้ผ่านเว็บบนมือถือได้เต็มรูปแบบ และติดตั้งเป็นแอปบนหน้าจอหลักได้

ถ้าเลิกใช้ ข้อมูลเป็นของใคร

ของคุณทั้งหมด ข้อมูลอยู่ในฐานข้อมูลของคุณเอง และ export ได้ทุกเมื่อ

อยากเห็นของจริงก่อนตัดสินใจ
